Про дані

MyKep зберігає в цьому браузері групу, налаштування, проходження вступу, випадковий UID і офлайн-розклад. Сервер записує час запиту, UID, групу, тип події, режим PWA/браузера та User-Agent для статистики. Автооновлення позначаються окремо від відкриттів і дій. Старі записи означають успішні запити API й можуть включати автооновлення. Деталі історії автоматично не видаляються. IP використовується захистом адмінки; цей опис не охоплює окремі журнали хостингу. Окрема статистика хостингу не входить до цього опису. З питаннями щодо даних: @oddxq
