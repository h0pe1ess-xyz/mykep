# Перевірки оновлення

## Виконано в the Computer

Python: 13 перевірок виконано успішно. Перевірено точне зіставлення груп, об’єднані групи, тривалість змін, навчальні тижні, перевірку snapshot, ОС-блокування, 200 одночасних спроб refresh → один виклик джерела, відновлення кешу з SQLite, збереження старих даних при помилці, обмеження черги, завершальний запис, виключення списку груп зі статистики та ідемпотентність позначок доставки звітів.

JavaScript: 20 перевірок виконано успішно в Node.js, із тестовими DOM-об’єктами. Перевірено визначення iOS/iPadOS/Android/WebView/Telegram, ручну Android-інструкцію без `beforeinstallprompt`, додаткове підтвердження браузерного режиму, одноразовий native install prompt, пропуск підказки у PWA, екранування тексту, пошкоджений JSON, ізоляцію кешу за групою/тривалістю/тижнем, помилки без хибного «вихідного дня», офлайн-fallback, об’єднання запитів списку груп і існування ресурсів service worker.

Усі Python-файли скомпільовано перевіркою синтаксису, усі JS-файли перевірено `node --check`. Це не замінює запуск вебсервера або перевірку реального браузера.

Синтетичний локальний сценарій: **200 паралельних задач, 200 груп, 2 000 операцій побудови/серіалізації розкладу й запису статистики**, 2 000 подій у тимчасовій SQLite, 200 тестових UID, 0 помилок побудови, 0 втрачених подій. Один запуск зайняв 0,639 с разом із завершенням запису. Це тест сервісного шару в the Computer, **не HTTP-навантажувальний тест VPS** і не обіцянка такої швидкості production.

Для перевірки SQLite використано чистий Python-модуль `aiosqlite` із наданого архіву. Старі `.venv`, база користувачів і її вміст не включені в результат.

## Що залишилося перевірити

6 реальних FastAPI/HTTP integration-тестів і 4 unit-тести життєвого циклу бота додані, але **пропущені** в the Computer: тут немає робочих FastAPI/httpx/python-telegram-bot, а встановлення пакетів недоступне. Повторіть весь набір у повному локальному середовищі: пропущених тестів через відсутність залежностей не повинно бути. Справжні Telegram polling, токен, admin-доступ, webhook-конфлікти та доставка повідомлень не перевірялися.

Немає виконаної браузерної емуляції, скриншотних тестів або перевірки на фізичному iPhone 13 mini. CSS адаптовано під вузькі й низькі viewport-и, safe areas та visualViewport клавіатури; візуальний результат потребує перевірки на пристроях. До upstream коледжу та VPS не підключалися. ZIP містить виправлення й тести, а не підтверджений production-деплой.

## Матриця ручної перевірки перед релізом

| Середовище / сценарій | Очікування |
| --- | --- |
| 320×568, 360×640, 375×812 (iPhone 13 mini), 390×844, 430×932 | Ті самі кольори, таймер, картки й іконки; без горизонтального обрізання; вертикальний контент доступний прокручуванням |
| iPhone Safari, звичайний та встановлений режим | Коректні safe areas; навігація не перекриває останню картку; у PWA немає примусової інструкції |
| Поворот екрана й клавіатура у пошуку груп | Кнопки й список доступні прокручуванням, input не спричиняє автоматичне збільшення через дрібний шрифт |
| Перший запуск і прямий URL schedule/settings | Перехід до онбордингу; список груп, пошук, вибір; не можна мовчки зберегти порожню групу |
| API груп не відповідає | Повідомлення, кнопка повтору, можливість ручного введення повної назви |
| Android Chrome без install event | Ручна інструкція все одно видима |
| Android із `beforeinstallprompt` | Кнопка викликає native prompt; відмова не ламає ручну інструкцію |
| Telegram iOS/Android | Підказка відкрити Safari / зовнішній браузер; копіювання посилання та fallback при забороні clipboard |
| Telegram із прихованим UA | Загальна підказка про вбудований браузер усе одно доступна; не вимагати неможливого 100% UA-розпізнавання |
| «Продовжити у браузері» | Ще одне підтвердження; повернення до встановлення; після згоди переходи між сторінками не перепитують у тій самій сесії |
| Встановлення на iOS/Android | Manifest, 192/512 PNG, SW install/activate, запуск з іконки |
| Онлайн → офлайн, той самий тиждень | Збережений розклад із видимим попередженням |
| Немає мережі й немає валідного кешу | Помилка + повтор, а не неправдивий «вихідний день» |
| Зміна групи, тривалості або тижня | Не використовується чужий/старий локальний розклад |
| Довгі назви предметів, викладачів, аудиторій | Переноси, без накладання на час чи перемикачі |
| Оновлення попереднього PWA | Нові JS/CSS, збереження групи й UID; старий cache-list з неіснуючим `/app.js` більше не використовується |
| Бот `/stats`, `/week`, `/users`, `/groups`, `/live`, `/hours`, `/platforms` | Відповіді дозволеним адміністраторам; без даних для сторонніх |
| Перезапуск, втрата мережі, дубль poller-а | Немає осиротілих report-задач; зрозумілі логи без токена; конфлікт потребує виправлення конфігурації |
| 200 HTTP-клієнтів на staging | Перевірити скриптом і метриками VPS; не виводити висновок лише з синтетичного тесту |

Кнопки, порядок блоків і характер інтерфейсу збережені. «Однаковий дизайн» не означає піксельно однакові фізичні розміри на різних екранах: на малому телефоні використано переноси та прокручування, а не масштабування всього сайту до нечитабельного стану.
